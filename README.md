# Reachy Mini App Authoring

This folder contains a portable agent skill for creating, modifying, debugging, and locally verifying user-facing Reachy Mini apps. It routes agents through the appropriate JavaScript/Web or Python workflow and links to the project's canonical documentation for details that may change.

## Contents

- [SKILL.md](SKILL.md): Entry point, scope, app-path selection, required planning and approval steps, and authorization boundaries.
- [references/javascript.md](references/javascript.md): JavaScript/Web app workflow, local checks, and user-authorized deployment guidance.
- [references/python.md](references/python.md): Python app workflow, required app assistant, SDK usage notes, and deployment boundaries.
- [references/setup-and-testing.md](references/setup-and-testing.md): Environment setup, simulation-first testing, hardware authorization, and limitations.
- [GLOSSARY.md](GLOSSARY.md): Canonical domain terms used by this skill.

The bundled guidance is a concise snapshot, not a replacement for current upstream docs. Consult the linked Reachy Mini documentation when available and flag conflicts or uncertainty before consequential actions.
